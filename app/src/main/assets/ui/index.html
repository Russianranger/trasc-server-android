Gameplay & zones

Rule set

These are available zone processes. Dynamic zone gameplay records can be inspected and edited in Database → SQL. Start with 3 workers on the Thor.

Zone:StateSavingOnShutdown also controls loading saved state in this fork. Disabling it retains existing saved rows.

All server rules

Open a category to edit its rules. Experience multipliers are in Character; zone persistence is in Zone. Search names or descriptions to find a setting.

Types, descriptions and defaults come from your imported source where available. Established limits are checked before saving; undocumented database rules remain editable as text. Negative disable values are preserved.

Load database settings first.
