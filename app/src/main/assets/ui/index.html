What do these options do?


Graphics
Turnip targets Qualcomm Adreno hardware.


Turnip driver
Stop the client before switching drivers. Both are included in the app. If 26.0.0 has problems, select 24.3.4 and relaunch. The first run with another driver may take longer to compile shaders.


NPC rendering (Turnip)
Recommended uses the exact 0.4.2 settings confirmed to fix NPC models. The 0.4.3 direct-mapping experiment did not fix names and can break models. Relaunch after changing this option.


Display presentation
Native Surface bypasses RFB pixel decoding and Java Bitmaps. X11 readback remains. Falls back to the current display on failure. Compare the same scene before keeping it.


Display update limit
Relaunch to apply. Display updates are not game FPS. The gear menu shows stage timings; Export Logs includes both paths’ measurements.


Boat investigation
Records a selected ship and your passenger state to diagnose falling through decks or sliding. Compile and deploy dinput8.dll with 0.5.2 or newer once, then select the ship and try boarding and riding for 1–2 minutes. Export logs after stopping the client. This diagnostic option does not change collision or movement.


First-person spell particles
Tests a fix for spell effects missing until you switch views. Compile and deploy dinput8.dll with this app once, then relaunch. Compare Diagnostics only and Repair with a fresh login and first-person cast; export logs afterward. Original behavior disables this adapter.


Graphics threading (WineD3D only)
Single thread removes Wine’s graphics command queue. Single + OpenGL worker keeps that choice and lets Mesa batch OpenGL commands on a native worker. Compare after relaunching; either can help or hurt. The display bar reports Wine presentations and new bitmap draws separately. Neither measures monitor refresh.


Runtime mode
Automatic tests faster file and system-call handling before Wine starts. Select Compatibility if launching becomes unstable. Imported game files already use private internal storage.


CPU affinity
Allow available cores removes the game’s CPU 0 restriction within the cores Android currently allows this app. It does not edit your client settings file. Stop and relaunch to compare.


CPU profile
Use Balanced for normal play. The latest Thor test found lower FPS and no name or spell-sound improvement with Legacy math accuracy. Saved choices are retained.


Fullscreen game
Fills the display without the game window border. Launch applies the selected resolution and keeps a backup of your previous display settings. Controls are in the top-right gear menu.


Game audio
Plays through Android media audio. Use the device volume buttons and the game’s sound settings. Relaunch after changing this option.


Show DXVK FPS / statistics HUD
Turn off for an unobstructed game screen. Applies to Turnip + DXVK on the next launch; stop and relaunch the client to change it.


Faster spell loading (experimental)
Reduces repeated spell-checksum work and uses a faster integer parser. Off by default. Compile and deploy dinput8.dll with 0.4.19 or newer, then relaunch to compare server select → character select. Your spell files stay unchanged.


Reduce model-loading pauses (experimental)
Tries shorter waits while loading global models. Default off; compare fresh launches with the same settings and export logs. Compile and deploy dinput8.dll with this app once, then relaunch. UI and model loading timings are recorded with either choice. Leave Faster spell loading at its working setting.


Recenter only during camera look (experimental)
Requires dinput8.dll compiled and deployed with app 0.4.18 or newer. Recenter only while looking around in-world; startup and inventory keep a free pointer. Stop and relaunch to apply. Older DLLs use normal mouse movement.


Sound diagnostics (short tests)
Checks both installed spell tables, particle settings, the reported particle texture and packed spell sounds, and keeps audio startup events separately from repetitive mixer logs. Export Logs after a short spell test, then turn this off for normal play.


Verbose Wine diagnostics (slower)
Leave off for normal play. Detailed diagnostics can greatly slow loading. Wine logs retain up to two current 8 MiB segments. Choose how many older logs to keep on the Logs tab.






Preparation & recovery help
Export & sync client data on the Server tab overwrites all four generated files in both the local client root and Resources folder, with backups. Export and Prepare respect spell compatibility mode. Restore full spell files turns filtering off. Prepare also updates eqhost.txt and applies the selected display mode. Open the server runtime for Prepare; start the server before logging in. Android Back returns here while the client stays open. Saved controller bindings apply inside the display; use its Keyboard button for text. Fixes → Wine prefix recovery creates a fresh Windows environment and opens its desktop after preserving the old prefix in client/prefix-backups. Imported game files and server data are retained. Disable native dinput8 only to compare startup without your modification.
