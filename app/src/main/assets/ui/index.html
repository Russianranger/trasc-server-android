Gameplay & zones

Rule set

These are available zone processes. Dynamic zone gameplay records can be inspected and edited in Database → SQL. Start with 3 workers on the Thor.

Zone:StateSavingOnShutdown also controls loading saved state in this fork. Disabling it retains existing saved rows.

Experience multipliers

RaidExpMultiplier is the raid penalty fraction (0.30 means 30% reduction). Final multipliers apply separately. Values are loaded from your database; unset rules use the server’s compiled defaults.

Restart the server to apply changes consistently to every process.

Local edits

The runtime directory is separate from downloaded source. Your maps, database and editable quests survive source updates and recompilation.

To adopt quest changes from an update, copy the selected files from sources/current into server/quests with the file manager.
