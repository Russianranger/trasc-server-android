# 1999 and Necromancer launcher themes

The **Launcher theme** selector now includes **1999** alongside Default, Necromancer and Monk. The new theme pairs parchment lettering with bronze bevels, square stone panels and four generated scenes resembling original 1999 EverQuest gameplay, with low-polygon models, coarse repeating textures and simple lighting. Art is packaged offline as WebP, without a network request or changes to world/client settings.

| Artwork | Destinations |
| --- | --- |
| City gates | Play, Setup, Server |
| Elven wilds | Gameplay, Appearance, Client |
| Wizard's spellbook | Spire, Database, Bots, Logs |
| Dragon expedition | Updates & builds, Backups & files, Fixes |

Necromancer retains its black and dark-red palette and four paintings. Realistically textured dry bones replace panel border lines and inset outlines on tiles, the runtime toolbar, profile bar, primary and secondary navigation, Advanced navigation tools, setup checklist and update checklist. The frame is a bundled transparent nine-slice WebP, with pointer events disabled so it does not cover touch or controller targets. Narrow layouts use thinner frames. All themed Play and Appearance destinations now use their own theme's artwork.

Appearance persists across reloads and all three world profiles. Both the browser and native all-profile backup/restore validators accept `1999`. Unknown saved values still fall back to Default; theme changes do not invoke runtime operations, change client options or overwrite unrelated preferences.

## Assets and provenance

The four backgrounds were regenerated from the earlier paintings using the built-in image-generation tool and the complete prompts below. These are generated interpretations of period game rendering, not actual historical screenshots. The bone frame was generated separately with transparency. PNG outputs were encoded as WebP without changing their composition. Earlier artwork remains in Git history. Final project paths:

- `app/src/main/assets/ui/theme-1999-gates.webp`
- `app/src/main/assets/ui/theme-1999-wilds.webp`
- `app/src/main/assets/ui/theme-1999-spellbook.webp`
- `app/src/main/assets/ui/theme-1999-dragon.webp`
- `app/src/main/assets/ui/theme-necromancer-bones.webp`

## Verification

Run `node tests/ui_themes.cjs` for scene routing, decoding, transparent bone frames replacing border rules, contrast, reload/profile persistence, safe storage fallback and touch layout. Set `THEME_SCREENSHOT_DIR=ui-reports/themes-retro` to capture the themed screens. Runtime controls across all themes are covered by `tests/ui_session.cjs`; TAKP layouts by `tests/ui_takp.cjs`; full-profile appearance export/restoration by `tests/ui_all_sessions.cjs`. The improved-UI CI builds and lints the signed test APK using the verified 0.6.42 native payload and checks that the new artwork and frame bytes are packaged exactly.

On the AYN Thor, select 1999, visit each of the four scene groups, close/reopen the app and switch world profiles. Check that text remains readable and all six runtime buttons work. Select Necromancer and check that textured bones replace the old straight outlines on Play, Manage, Advanced panels, setup and update checklists, including controller focus and collapsed cards. Export/restore an all-profile backup with 1999 selected; restore only a disposable backup or use your usual backup precautions. These device checks complement browser/host tests.

### Necromancer bone frame

Use case: product-mockup. Asset type: transparent square nine-slice UI border texture for a dark necromancer game theme. Create a complete square frame made ONLY from realistic dry aged human-style skeletal bones. Photorealistic physical bone material, ivory and yellowed beige, porous joint ends, fine cracks, natural asymmetrical shafts, clear rounded condyles and believable anatomy, soft restrained studio shading. Along each of the four sides place two long femur/tibia-style bones end to end, all aligned exactly horizontally or vertically, forming connected perimeter rails. At the four corners the bone joints overlap naturally; no cartoon skull icons. The outer frame is close to the canvas edge, and all bone material stays within the outer 12 percent band on each side; keep the middle 76 percent square completely empty and genuinely transparent. Square canvas 1024x1024. View straight down orthographically, no perspective. Consistent thickness and alignment suitable for CSS nine-slice borders. Bones themselves form the complete outline: no straight drawn lines, no solid rectangular base, no metal, no wood, no extra inner frame, no colored background, no lettering, no shadows filling the center. Dry clean bones only, no flesh or gore. Transparent background including central opening and small gaps between irregular bone silhouettes. The result must look like textured real skeletal bone, never a dog-biscuit icon, flat vector or cartoon.
