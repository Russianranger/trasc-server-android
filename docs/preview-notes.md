# TRASC Android 0.6.15 / code 64

The Monk launcher theme now uses sea blue surfaces and light red accents with
four original offline background paintings: a temple, meditation scene, dojo
and martial combat scene. Launcher sections have distinct Monk artwork.

Choose **Monk** from **Launcher theme** in the **World profile** bar. The theme
persists across reloads and world profiles. **Default** and **Necromancer** retain
their existing palettes and artwork.

Install this APK as an update. The artwork and palette changes affect the
launcher only; the existing compiled Traditional server, imported RoF2 client,
Wine prefix, runtime, DirectX helpers, controller bindings, character preferences
and era rules remain. This scoped build reuses all 21 verified native components
from 0.6.14, including the camera proxy, without server, runtime or native
component compilation.

For the background and palette acceptance checks, see
[launcher theme guide](https://github.com/Russianranger/trasc-server-android/blob/main/docs/launcher-themes-0615.md).
